# Mewstats
No-op.

## Features
### Throw, Sky, and MLS stats
* Throw Speed
  > Shows player's speed when a flashbang is thrown.
* Throw Angle
  > Shows player's pitch angle when a flashbang is thrown.
* Throw Time
  > Shows time it took to release a flashbang after a jump.
* Throw Deviation
  > Shows angle between a thrown flashbang velocity and player's partner velocity directions.
* Throw Status
  > Shows NoJump label if a flashbang was thrown without a jump.
* Sky Stats
  > Shows how strength a sky jump was, printed for both players.
* Mls Stats
  > Shows information on X's, printed for both players.

### Cosmetics, short names, and chat themes
* Short Names
  > Shows short names instead of their long ones for throw stats.
* Crouch Name
  > Select which long crouch name you prefer, the Duck or the Crouch.
* Color Values
  > Shows how good player's throw stat was, from red to green colors.
* Value Precision
  > Select how precise player's throw stat will be, from .0 to .1 precision.
* Chat Theme
  > Select which colors to use for throw, sky and MLS stats — Standard, Lilac, Ice, Mint.
* Chat Separator
  > Select which separator to use to separate throw stats from each other — Space, Line.
* Chat Sound
  > Plays the chat's tick sound when throw, sky or MLS stat is printed.

## Commands
* /bs
  > Opens the main menu of the plugin.
* /bsall
  > Remembers what you had enabled and enables or disables everything.
* /bssnap
  > Shows what snapshot is currently in use and what it remembered.
